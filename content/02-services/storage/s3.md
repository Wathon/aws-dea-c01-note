# 📦 Amazon S3 (Simple Storage Service)

- **Category**: Storage
- **Primary Use Case**: Centralized Data Lake Storage, Object Backup, Raw Data Landing Zone
- **Slide Reference**: Pages 77–138 in [[AWSCertifiedDataEngineerSlides.pdf]]
- **Hub Links**: [[index]] | [[service-catalog]] | [[domain-2-data-store-management]]

## 1. High-Level Summary

Amazon S3 is an object storage service offering industry-leading scalability, data availability, security, and performance. In AWS Data Engineering, S3 serves as the backbone of modern Data Lakes, decoupling storage from compute for tools like [[athena]], [[glue]], [[emr]], and [[redshift]] (Spectrum).

## 2. Key Technical Concepts & Features

### S3 Storage Classes Matrix

| Storage Class                     | Durability         | Availability | Min Retention | Access Latency  | Ideal Use Case                                                                   |
| --------------------------------- | ------------------ | ------------ | ------------- | --------------- | -------------------------------------------------------------------------------- |
| **S3 Standard**                   | 11 9's             | 99.99%       | None          | Milliseconds    | Active, frequently accessed data lake landing zone                               |
| **S3 Intelligent-Tiering**        | 11 9's             | 99.9%        | None          | Milliseconds    | Unknown or changing access patterns (auto-tiers without retrieval fees)          |
| **S3 Standard-IA**                | 11 9's             | 99.9%        | 30 days       | Milliseconds    | Infrequently accessed data, rapid retrieval needed                               |
| **S3 One Zone-IA**                | 11 9's (single AZ) | 99.5%        | 30 days       | Milliseconds    | Non-critical, reproducible data stored in 1 AZ                                   |
| **S3 Express One Zone**           | 11 9's (single AZ) | 99.9%        | None          | Single-digit ms | **High-performance analytics (EMR, Athena, ML training)**                        |
| **S3 Glacier Instant Retrieval**  | 11 9's             | 99.9%        | 90 days       | Milliseconds    | Archive data requiring immediate retrieval                                       |
| **S3 Glacier Flexible Retrieval** | 11 9's             | 99.9%        | 90 days       | Mins to Hours   | Backup data, flexible retrieval (Expedited: 1-5 min, Std: 3-5 hr, Bulk: 5-12 hr) |
| **S3 Glacier Deep Archive**       | 11 9's             | 99.9%        | 180 days      | 12 to 48 Hours  | Lowest cost storage for compliance & long-term retention                         |

### S3 Advanced Features for DEA-C01

1. **S3 Lifecycle Rules**:
   - **Transition Actions**: Automatically move objects between storage classes (e.g., Standard -> Standard-IA after 30 days -> Glacier after 90 days).
   - **Expiration Actions**: Permanently delete objects after $X$ days or remove old non-current object versions.

2. **S3 Security & Access Control**:
   - **Bucket Policies**: JSON access control policies attached to buckets (can enforce HTTPS/TLS via `aws:SecureTransport`, block unencrypted uploads).
   - **IAM Policies**: User-level permissions (`s3:GetObject`, `s3:PutObject`).
   - **Block Public Access**: Account/Bucket level safety setting.
   - **Access Points & Multi-Region Access Points**: Simplify managing data access at scale for distinct applications.

3. **S3 Object Lock (Immutability)**:
   - Enforces **WORM (Write Once Read Many)** state. Prevent deletion or modification of objects.
   - **Governance Mode**: Users with special permissions (`s3:BypassGovernanceRetention`) can overwrite/delete.
   - **Compliance Mode**: NO ONE (including root user) can overwrite or delete until retention period expires!

4. **S3 Replication**:
   - **Cross-Region Replication (CRR)**: Replicate objects to another AWS Region for compliance or lower latency.
   - **Same-Region Replication (SRR)**: Replicate within same region for log aggregation, live sync across accounts.
   - Requires S3 Versioning enabled!

5. **S3 Event Notifications**:
   - Trigger automated actions on `s3:ObjectCreated:*` or `s3:ObjectRemoved:*`.
   - Native targets: [[sqs-and-sns]] (SQS, SNS), [[lambda]], or [[cloudwatch-and-eventbridge]] (EventBridge).

6. **S3 Storage Lens & Inventory**:
   - **S3 Inventory**: Generates daily/weekly CSV/ORC/Parquet reports of objects for analytics.
   - **S3 Storage Lens**: Organization-wide visibility into object storage usage, cost optimization recommendations, and security metrics.

## 3. DEA-C01 Exam Tips & Decision Triggers

> [!IMPORTANT]
> **Key Exam Distinctions & Keywords**:
>
> - **Single-digit millisecond latency for compute/analytics**: Choose **S3 Express One Zone**.
> - **Unknown access pattern without retrieval fees**: Choose **S3 Intelligent-Tiering**.
> - **Regulatory compliance strict WORM requirement**: Choose **S3 Object Lock Compliance Mode**.
> - **Enforce encryption in transit**: Add S3 Bucket Policy condition `"aws:SecureTransport": "false"` with `Effect: Deny`.
> - **Query large data in S3 directly using SQL**: Use [[athena]] or [[redshift]] Spectrum.
