## 1. High-Level Summary (အဓိက အကျဉ်းချုပ်)

Amazon S3 သည် industry-leading scalability, data availability, security နှင့် performance ကို ပေးစွမ်းနိုင်သော object storage service တစ်ခုဖြစ်သည်။ AWS Data Engineering တွင် S3 သည် [[mm/02-services/analytics-streaming/athena/athena|athena]], [[mm/02-services/analytics-streaming/glue/glue|glue]], [[mm/02-services/analytics-streaming/emr/emr|emr]] နှင့် [[mm/02-services/database/redshift|redshift]] (Spectrum) ကဲ့သို့သော tool များအတွက် storage နှင့် compute ကို ခွဲခြားပေးပြီး (decoupling) ခေတ်သစ် Data Lakes များ၏ ကျောရိုး (backbone) အဖြစ် ဆောင်ရွက်ပေးသည်။

## 2. Key Technical Concepts & Features (အဓိက နည်းပညာဆိုင်ရာ သဘောတရားများနှင့် လုပ်ဆောင်ချက်များ)

### S3 Storage Classes Matrix

| Storage Class                     | Durability         | Availability | Min Retention | Access Latency  | Ideal Use Case (အသင့်တော်ဆုံး အသုံးပြုမှု)                                     |
| --------------------------------- | ------------------ | ------------ | ------------- | --------------- | -------------------------------------------------------------------------------- |
| **S3 Standard**                   | 11 9's             | 99.99%       | None          | Milliseconds    | Active, အမြဲတမ်းသုံးနေရသော (frequently accessed) data lake landing zone         |
| **S3 Intelligent-Tiering**        | 11 9's             | 99.9%        | None          | Milliseconds    | မသိနိုင်သော သို့မဟုတ် ပြောင်းလဲနေသော access patterns (retrieval fees မပါဘဲ auto-tiers လုပ်ပေးသည်) |
| **S3 Standard-IA**                | 11 9's             | 99.9%        | 30 days       | Milliseconds    | မကြာခဏ အသုံးမပြုသော (Infrequently accessed) data, အမြန်ပြန်လည်ရယူရန် (rapid retrieval) လိုအပ်သောအခါ |
| **S3 One Zone-IA**                | 11 9's (single AZ) | 99.5%        | 30 days       | Milliseconds    | အရေးမကြီးသော (Non-critical)၊ ပြန်လည်တည်ဆောက်နိုင်သော (reproducible) 1 AZ တွင် သိမ်းထားသော data |
| **S3 Express One Zone**           | 11 9's (single AZ) | 99.9%        | None          | Single-digit ms | **High-performance analytics (EMR, Athena, ML training)**                        |
| **S3 Glacier Instant Retrieval**  | 11 9's             | 99.9%        | 90 days       | Milliseconds    | ချက်ချင်းပြန်လည်ရယူရန် လိုအပ်သော (immediate retrieval) Archive data                |
| **S3 Glacier Flexible Retrieval** | 11 9's             | 99.9%        | 90 days       | Mins to Hours   | Backup data, flexible retrieval (Expedited: 1-5 min, Std: 3-5 hr, Bulk: 5-12 hr) |
| **S3 Glacier Deep Archive**       | 11 9's             | 99.9%        | 180 days      | 12 to 48 Hours  | Compliance နှင့် ရေရှည်သိမ်းဆည်းရန်အတွက် အသက်သာဆုံး cost (Lowest cost) storage |

### S3 Advanced Features for DEA-C01 (DEA-C01 အတွက် S3 အဆင့်မြင့် လုပ်ဆောင်ချက်များ)

1. **S3 Lifecycle Rules**:
   - **Transition Actions**: Storage classes များအကြား object များကို အလိုအလျောက် ပြောင်းရွှေ့ပေးသည် (ဥပမာ - 30 ရက်ကြာပြီးနောက် Standard -> Standard-IA သို့၊ 90 ရက်ကြာပြီးနောက် Glacier သို့)။
   - **Expiration Actions**: $X$ ရက်အကြာတွင် object များကို အပြီးတိုင် ဖျက်ပစ်သည် သို့မဟုတ် အဟောင်းဖြစ်သော (non-current) object version များကို ဖယ်ရှားသည်။

2. **S3 Security & Access Control**:
   - **Bucket Policies**: Bucket များတွင် တွဲထားသော JSON access control policies (HTTPS/TLS ကို `aws:SecureTransport` ဖြင့် အတင်းအကျပ် (enforce) လုပ်နိုင်သည်၊ encrypt မလုပ်ထားသော upload များကို block လုပ်နိုင်သည်)။
   - **IAM Policies**: User အဆင့် ခွင့်ပြုချက်များ (User-level permissions) (`s3:GetObject`, `s3:PutObject`).
   - **Block Public Access**: Account/Bucket အဆင့် လုံခြုံရေး setting။
   - **Access Points & Multi-Region Access Points**: မတူညီသော application များအတွက် data access အား ပမာဏများစွာ (at scale) ဖြင့် စီမံခန့်ခွဲရာတွင် လွယ်ကူစေသည်။

3. **S3 Object Lock (Immutability)**:
   - **WORM (Write Once Read Many)** အခြေအနေကို အတင်းအကျပ်ကျင့်သုံးသည် (enforces)။ Object များကို ဖျက်ပစ်ခြင်း သို့မဟုတ် ပြင်ဆင်ခြင်းကို တားဆီးသည်။
   - **Governance Mode**: အထူး ခွင့်ပြုချက် (`s3:BypassGovernanceRetention`) ရှိသူများသာ overwrite/delete လုပ်နိုင်သည်။
   - **Compliance Mode**: မည်သူမျှ (root user အပါအဝင်) retention period မကုန်မချင်း overwrite သို့မဟုတ် delete လုပ်၍မရပါ!

4. **S3 Replication**:
   - **Cross-Region Replication (CRR)**: Compliance အတွက်ဖြစ်စေ၊ latency လျှော့ချရန်အတွက်ဖြစ်စေ အခြား AWS Region သို့ object များကို replicate လုပ်သည်။
   - **Same-Region Replication (SRR)**: Log aggregation အတွက်ဖြစ်စေ၊ account များအကြား live sync လုပ်ရန်ဖြစ်စေ တူညီသော region အတွင်း replicate လုပ်သည်။
   - S3 Versioning ကို enable လုပ်ထားရန် လိုအပ်သည်!

5. **S3 Event Notifications**:
   - `s3:ObjectCreated:*` သို့မဟုတ် `s3:ObjectRemoved:*` အပေါ်တွင် automated actions များကို trigger လုပ်သည်။
   - Native targets: [[mm/02-services/integration/sqs-and-sns|sqs-and-sns]] (SQS, SNS), [[mm/02-services/compute-containers/lambda|lambda]], သို့မဟုတ် [[mm/02-services/networking-monitoring/cloudwatch-and-eventbridge|cloudwatch-and-eventbridge]] (EventBridge)။

6. **S3 Storage Lens & Inventory**:
   - **S3 Inventory**: Analytics အတွက် object များ၏ နေ့စဉ်/အပတ်စဉ် CSV/ORC/Parquet report များကို ထုတ်ပေးသည်။
   - **S3 Storage Lens**: Organization တစ်ခုလုံးအတွက် object storage အသုံးပြုမှုမြင်ကွင်း (visibility)၊ ကုန်ကျစရိတ် သက်သာစေရန် (cost optimization) အကြံပြုချက်များ နှင့် လုံခြုံရေး metrics များ။

## 3. DEA-C01 Exam Tips & Decision Triggers

> [!IMPORTANT]
> **Key Exam Distinctions & Keywords (စာမေးပွဲအတွက် အရေးကြီးသော ကွဲပြားချက်များ နှင့် အဓိကစကားလုံးများ)**:
>
> - **Single-digit millisecond latency for compute/analytics**: **S3 Express One Zone** ကိုရွေးပါ။
> - **Unknown access pattern without retrieval fees**: **S3 Intelligent-Tiering** ကိုရွေးပါ။
> - **Regulatory compliance strict WORM requirement**: **S3 Object Lock Compliance Mode** ကိုရွေးပါ။
> - **Enforce encryption in transit**: `Effect: Deny` ဖြင့် S3 Bucket Policy condition `"aws:SecureTransport": "false"` ကို ထည့်ပါ။
> - **Query large data in S3 directly using SQL**: [[mm/02-services/analytics-streaming/athena/athena|athena]] သို့မဟုတ် [[mm/02-services/database/redshift|redshift]] Spectrum ကိုအသုံးပြုပါ။
