## 1. High-Level Summary

**AWS Glue DataBrew** is a visual data preparation tool that makes it easy for data analysts and data scientists to clean and normalize data to prepare it for analytics and machine learning. In the **AWS Certified Data Engineer – Associate (DEA-C01)** exam, DataBrew is consistently positioned as the solution for **no-code** data preparation tasks.

---

## 2. Core Capabilities

- **Visual Interface**: Provides a spreadsheet-like interface where users can visually inspect data.
- **Pre-built Transformations**: Offers over 250 built-in transformations to automate data preparation tasks (e.g., filtering anomalies, converting data formats, correcting invalid values, handling missing values) without writing any code.
- **Data Profiling**: Generates visual data profiles that display column statistics, cardinality, correlation, and distributions.
- **Data Lineage**: Visually maps the origin of the data and what transformations were applied.
